# 星野 Xingye Bot v0.4.1-dev+0 更新报告

## 新增功能

### 1. 高考志愿顾问（私聊专用）
- 用户发送 `高考志愿` 进入咨询模式，与雪峰Agent多轮对话
- 自动提取省份、位次、分数、专业偏好，查询24省42万条官方录取数据
- 返回冲稳保三段式推荐，支持反复细化查询条件
- 发送 `退出高考志愿` 结束咨询
- 群聊中发送 `高考志愿` 提示"仅限私聊使用"
- 需配合 Xuefeng Agent 桥接服务使用（`gaokao_bridge.py` :8766）

### 2. 好友申请管理与白名单
- 管理面板新增「好友管理」标签页
- **好友白名单**：添加/移除 QQ 号，白名单内的好友申请自动通过
- **申请记录**：显示所有好友申请（待处理/已同意/已拒绝），含申请时间、备注
- **手动操作**：对待处理的申请可手动点击「同意」或「拒绝」
- 数据持久化到 `data/friend_whitelist.json` 和 `data/friend_requests.json`
